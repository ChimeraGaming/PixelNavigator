Maps live here to save APK space, grouped by system and the matching game series in PixelNavigator.

Package layout: `Maps/<system>/<series>/<game>/<version>/<package>.zip`.

For example: `Maps/GBA/dragon_ball_z/dragon_ball_z_legacy_of_goku/usa-rev0/dragon_ball_z_legacy_of_goku_maps_vusa-rev0_part01.zip`.

Series folders include `pokemon`, `dragon_ball_z`, `castlevania`, `mega_man`, `metroid` and `breath_of_fire`. Mariomon belongs to the app's Pokemon group. Existing game IDs, version folders and ZIP contents are preserved.

Upload the complete reorganized `Maps/` folder alongside the matching APK update. Download URLs, package sizes and checksums are included in the APK, so an older build still expects the previous paths.
